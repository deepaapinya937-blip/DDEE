เครื่องมือตรวจสอบ iOS (iPhone & iPad Forensic Audit)

เทคนิคการตรวจสอบโปรแกรมนอก, ใบรับรององค์กร และประวัติแอปที่ถูกลบไปแล้วบนระบบ iOS

1. ตรวจเช็กโปรไฟล์และใบรับรององค์กร (Profiles & Certificates)

โปรแกรมนอก/ม็อดบน iOS (เช่น Scarlet, AltStore, PandaHelper หรือไฟล์ IPA โกงเกม) ต้องใช้ Profile หรือ Enterprise Certificate เสมอ

การตั้งค่า > ทั่วไป > VPN และการจัดการอุปกรณ์

⚠️ หากมีรายการ "แอปองค์กร" (Enterprise App) หรือ "โปรไฟล์การกำหนดค่า" ที่ไม่ใช่ของโรงเรียนหรือบริษัท แปลว่าเครื่องนั้นติดตั้งโปรแกรมนอกแน่นอน

2. ดูประวัติแอปที่เคยดาวน์โหลดทั้งหมด (แม้จะลบไปแล้ว)

Apple บันทึกทุกแอปที่ Apple ID เคยสั่งดาวน์โหลด แม้จะลบออกจากหน้าจอไปแล้ว:

App Store > รูปโปรไฟล์ > สินค้าที่ซื้อแล้ว > ไม่ได้อยู่ใน iPhone นี้

💡 สามารถค้นหาชื่อแอปย้อนหลังได้ทั้งหมด หากเคยโหลดมาจะขึ้นไอคอนก้อนเมฆ (Cloud Download)

3. ตรวจสอบผ่าน iOS Sysdiagnose & Backup Manifest

ดึงไฟล์ Log วินิจฉัยของ iOS เพื่อดู Bundle ID และประวัติ Crash/การติดตั้ง:

กด ปุ่มเพิ่มเสียง + ปุ่มลดเสียง + ปุ่มเปิด/ปิดเครื่อง พร้อมกัน 1 วินาที เพื่อสร้างไฟล์ Sysdiagnose หรือต่อคอมดึงข้อมูลผ่าน iTunes Backup

วิธีที่ 1: วาง Log จาก ADB

เสียบสายมือถือเข้ากับคอม แล้วเปิด Terminal/PowerShell เลือกคัดลอกคำสั่งด้านล่างเพื่อดึงข้อมูลเชิงลึก:

adb shell pm list packages -u
adb shell pm list packages -i
adb shell dumpsys usagestats

วิธีที่ 2: อัปโหลดไฟล์ประวัติ

รองรับไฟล์ Text, JSON หรือรายงานจาก Google My Activity / Takeout

คลิกเพื่อเลือกไฟล์ หรือลากไฟล์มาวางที่นี่
รองรับไฟล์ .txt, .json, .log, .csv

วิธีที่ 3: ตรวจสอบบนมือถือโดยตรง

📱 บน Android:

  • เข้า การตั้งค่า (Settings) > ความเป็นอยู่ที่ดีทางดิจิทัล (Digital Wellbeing)
  • หรือกดรหัสทดสอบในแป้นโทรศัพท์: *#*#4636#*#* แล้วเลือก Usage statistics

🍎 บน iPhone:

  • เข้า การตั้งค่า (Settings) > เวลาหน้าจอ (Screen Time) > ดูกิจกรรมทั้งหมด
